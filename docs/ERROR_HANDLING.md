# Common Errors

## INVALID_CUSTOMER_NUMBER

Customer reference invalid.

## PROVIDER_TIMEOUT

Electricity provider unavailable.

## PAYMENT_GATEWAY_ERROR

Payment provider failed.

## DUPLICATE_TRANSACTION

Transaction already processed.
