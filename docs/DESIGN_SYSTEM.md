## 2. Reglas UI

### Botones

- Bordes redondeados: 12px
- Altura mínima: 48px
- No usar más de 2 colores por botón

### Inputs

- Siempre mostrar label
- Validación visual obligatoria
- Iconos opcionales

### Cards

- Padding interno: 16px
- Sombra suave
- Evitar demasiados bordes

---

## 3. Responsive Design

### Mobile First

- Diseñar primero para móviles
- Luego adaptar tablet y desktop

### Breakpoints

- Mobile: 320px - 768px
- Tablet: 768px - 1024px
- Desktop: 1024px+

---

## 4. UX Rules

- No usar más de 3 acciones primarias por pantalla
- Evitar navegación profunda
- All critical action must confirm before

---

## 5. Animaciones

- Duración máxima: 300ms
- Evitar animaciones innecesarias
- Priorizar rendimiento
