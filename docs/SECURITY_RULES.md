# SECURITY RULES

# Authentication

- JWT mandatory
- Session expiration required
- Refresh token rotation

---

# Payment Security

- Validate webhook signatures
- Encrypt sensitive payloads
- Prevent replay attacks

---

# API Security

- Rate limiting
- IP validation
- HTTPS required
- API key rotation

---

# Audit Security

Store:

- Login attempts
- Payment attempts
- Failed requests
- Suspicious activity
